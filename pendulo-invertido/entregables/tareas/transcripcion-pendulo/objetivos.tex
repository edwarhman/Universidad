\section{Objetivos}

\begin{itemize}
    \item Modelar el sistema del prototipo de péndulo invertido.
    
    \item Estabilizar el sistema mediante el diseño de dos controladores PID en cascada.
    
    \item Estabilizar el sistema mediante realimentación de variables de estados utilizando observador identidad, observador de orden reducido y observador funcional lineal.
    
    \item Comparar el desempeño entre los controladores diseñados utilizando el tiempo de establecimiento y el sobre impulso.
\end{itemize}
