# Universidad — Repositorio de Trabajo

Repositorio central para proyectos, tareas, informes, prelaboratorios y parciales de la carrera de Ingeniería Eléctrica en la Universidad Central de Venezuela (UCV).

## Estructura

| Proyecto | Descripción | Lenguaje |
|---|---|---|
| `calculo-num-rico/` | Métodos numéricos | Python |
| `comunicaciones/` | Informes de Comunicaciones I | LaTeX |
| `informes-electronica/` | Informes y prelaboratorios de Electrónica | LaTeX + Python |
| `LIE II/` | Laboratorio de Ingeniería Eléctrica II | Python |
| `lineas-de-transmision/` | Tareas y parciales de Líneas de Transmisión | LaTeX |
| `maquinas-electricas-i/` | Informes, prelaboratorios, tareas y parciales | LaTeX |
| `mecanica/` | Tareas y parciales de Mecánica | LaTeX |
| `pendulo-invertido/` | Papers, artículos y presentaciones | LaTeX |
| `plantas-y-subestaciones/` | Tareas y parciales de Plantas y Subestaciones | LaTeX |
| `servicio/` | Servicio Comunitario (CEAPUCV) | LaTeX |
| `sistema-de-potencia/` | Tareas y parciales de Sistema de Potencia | LaTeX |
| `sistemas-de-control-II/` | Control de péndulo invertido | C (ESP-IDF) + Python + LaTeX |
| `teoria-electromagnetica/` | Formularios de Teoría Electromagnética | LaTeX |

## Convenciones

- Cada proyecto tiene un `feature_list.json` que define las tareas con su estado (`pending`, `in_progress`, `awaiting_review`, `done`, `blocked`).
- Se trabaja **una feature a la vez**.
- Los documentos LaTeX siguen el formato estándar UCV (portada, índice, contenido).
- Los PDFs compilados se almacenan junto a su fuente `.tex`.
