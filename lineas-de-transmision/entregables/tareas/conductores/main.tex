\section{Introducción}

Este informe presenta un análisis comparativo de los principales tipos de
conductores utilizados en líneas de transmisión eléctrica, evaluando sus
parámetros técnicos según las normas ASTM B, BRITISH y DIN.

\section{Tipos de Conductores}

\subsection{AAC (All Aluminum Conductor)}
Conductor de aluminio puro. Características:
\begin{itemize}
    \item Alta conductividad
    \item Bajo peso
    \item Menor resistencia mecánica
    \item Usos: distribución urbana, cortas distancias
\end{itemize}

\subsection{AAAC (All Aluminum Alloy Conductor)}
Conductor de aleación de aluminio. Características:
\begin{itemize}
    \item Mayor resistencia mecánica que AAC
    \item Buena relación resistencia-peso
    \item Resistencia a la corrosión
    \item Usos: líneas de media y larga distancia
\end{itemize}

\subsection{ACAR (Aluminum Conductor Alloy Reinforced)}
Conductor de aluminio con refuerzo de aleación. Características:
\begin{itemize}
    \item Combinación de alambres de aluminio puro y de aleación
    \item Balance entre conductividad y resistencia
    \item Usos: líneas que requieren mayor capacidad mecánica
\end{itemize}

\subsection{AACSR (Aluminum Alloy Conductor Steel Reinforced)}
Conductor de aleación de aluminio con refuerzo de acero. Características:
\begin{itemize}
    \item Alta resistencia mecánica (por el acero)
    \item Mayor peso
    \item Usos: grandes claros, condiciones extremas
\end{itemize}

\subsection{ACSR (Aluminum Conductor Steel Reinforced)}
Conductor de aluminio con refuerzo de acero. Características:
\begin{itemize}
    \item El más utilizado en transmisión
    \item Excelente relación resistencia-peso
    \item Variedad de configuraciones
    \item Usos: líneas de transmisión de alta tensión
\end{itemize}

\section{Parámetros de Comparación}

Para cada conductor se evaluarán los siguientes parámetros:

\begin{enumerate}
    \item \textbf{Calibre:} designación del tamaño del conductor (AWG, MCM, kcmil)
    \item \textbf{Sección:} área transversal del conductor (mm$^2$)
    \item \textbf{Diámetro:} diámetro exterior del conductor (mm)
    \item \textbf{Peso:} peso por unidad de longitud (kg/km)
    \item \textbf{Carga de rotura:} tensión máxima antes de la falla (kN)
    \item \textbf{Resistencia:} resistencia eléctrica a 20$^\circ$C ($\Omega$/km)
    \item \textbf{Ampacidad:} capacidad máxima de corriente (A)
    \item \textbf{Longitud máxima de despacho:} longitud máxima en bobina (m)
    \item \textbf{Peso neto:} peso del conductor sin empaque (kg)
    \item \textbf{Peso bruto:} peso del conductor con empaque (kg)
    \item \textbf{Marca:} fabricante o marca comercial
\end{enumerate}
